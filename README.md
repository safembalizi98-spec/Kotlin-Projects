## Getting Started

### Prerequisites
To run the Kotlin projects, install:

1. [IntelliJ IDEA](https://www.jetbrains.com/idea/)
2. [JDK](https://adoptium.net/)
3. Gradle (optional for projects using the Gradle Wrapper)

### Running a Project
1. Clone this repository:

   ```bash
   git clone https://github.com/safembalizi98-spec/Kotlin-Projects.git
   ```

2. Open the desired project folder in IntelliJ IDEA.

3. Allow Gradle to synchronize and download the required dependencies.

4. Locate the Kotlin file containing the `main()` function.

5. Run the application.
